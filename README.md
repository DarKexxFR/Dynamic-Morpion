# Endless Tic-Tac-Toe 🎮

Endless Tic-Tac-Toe is a Python (Tkinter) game with a strategic twist: a strict limit of 3 symbols per player. Place a 4th, and your oldest symbol disappears! The board never fills up. Play locally with a friend or challenge the AI (2 difficulty levels). A dynamic and endless take on a classic!

## 🌟 Features

- **Endless Mechanic:** A strict limit of 3 symbols per player. The oldest symbol is removed when a new one is placed, keeping the board constantly changing.
- **Local Multiplayer (PvP):** Play against a friend on the same computer.
- **Single Player vs AI (PvE):** Challenge the computer with two difficulty levels:
  - *Level 1 (Easy):* The bot plays completely randomly.
  - *Level 2 (Medium):* The bot actively tries to block your winning moves.
- **Graphical User Interface:** Clean, intuitive, and easy-to-use UI built with Python's standard `tkinter` library.

## 🛠️ Prerequisites & Installation

This project uses Python's standard `tkinter` library. No external dependencies are required.

1. Ensure you have Python installed on your machine (version 3.x recommended).
2. Clone this repository:
   ```bash
   git clone <https://github.com/your-username/your-repo-name.git>
   ```
3. Navigate to the project folder and run the game:
   ```bash
   python "morpion reda.py"
   ```
   *(Note: you can rename the python file to something like `main.py` for simplicity!)*

## 🎮 How to Play

1. Launch the game.
2. Choose your game mode (Local or Bot).
3. If playing against the Bot, select the AI difficulty level.
4. Click on empty squares to place your 'X' or 'O'.
5. **Remember:** You can only have 3 symbols active on the board. Placing a 4th will erase your very first symbol!
6. The first player to align 3 of their symbols (horizontally, vertically, or diagonally) wins the game.
