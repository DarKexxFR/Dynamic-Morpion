## <a id="english-version"></a> 🌍 English Version

**Dynamic-Morpion** (Endless Tic-Tac-Toe) is a Python game built with Tkinter that brings a strategic twist to the classic game: a strict limit of 3 symbols per player. Place a 4th, and your oldest symbol disappears! The board never fills up. Play locally with a friend or challenge the AI. 

*(Note: The game's graphical interface is currently in French).*

### 🌟 Features
- **Endless Mechanic:** A strict limit of 3 symbols per player. The oldest symbol is removed when a new one is placed, keeping the board constantly changing.
- **Local Multiplayer (PvP):** Play against a friend on the same computer.
- **Single Player vs AI (PvE):** Challenge the computer with two difficulty levels:
  - *Level 1 (Easy):* The bot plays completely randomly.
  - *Level 2 (Medium):* The bot actively tries to block your winning moves.
- **Graphical User Interface:** Clean and intuitive UI built with Python's standard `tkinter` library.

## <a id="version-française"></a> 🌍 Version Française

**Dynamic-Morpion** est un jeu développé en Python (avec Tkinter) qui apporte une touche stratégique au jeu classique : une limite stricte de 3 symboles par joueur. Si vous en placez un 4ème, votre symbole le plus ancien disparaît ! Le plateau ne se remplit donc jamais. Jouez en local avec un ami ou défiez l'IA.

## 🌟 Fonctionnalités
- **Mécanique infinie :** Une limite stricte de 3 symboles par joueur. Le symbole le plus ancien est supprimé lorsqu'un nouveau est placé, ce qui oblige à adapter sa stratégie en permanence.
- **Multijoueur local (PvP) :** Jouez contre un ami sur le même ordinateur.
- **Solo contre l'IA (PvE) :** Défiez l'ordinateur avec deux niveaux de difficulté :
  - *Niveau 1 (Facile) :* Le bot joue de manière totalement aléatoire.
  - *Niveau 2 (Moyen) :* Le bot tente activement de bloquer vos combinaisons gagnantes.
- **Interface Graphique (GUI) :** Une interface claire et simple d'utilisation, construite avec la bibliothèque standard `tkinter` de Python.
